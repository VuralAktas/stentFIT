# Examples

Runnable notebooks, straight from [`examples/`](https://github.com/VuralAktas/stentFIT/tree/main/examples) — the same files you would open and run yourself.

The first one turns a stent's surface mesh into a 1D beam model. The other three take that model and build a 4C simulation from it, one per simulation type. They all follow the same shape, so a reader who has seen one has seen them all.
